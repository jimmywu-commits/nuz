# 固定版型行銷素材編輯器（v27）

## 這一版（v27）修正了一個關鍵問題：換到別台電腦字體會跑掉

### 找到原因並修正
之前字體檔案（ShopeeNotoSans 三個字重）是用「相對路徑」的方式讀取 `fonts/` 資料夾裡的
`.woff2` 檔案。這代表 **`index.html` 必須跟 `fonts/` 資料夾放在同一層目錄下才能正常讀到字體**
——只要換到別台電腦時，只複製了 `index.html` 單一檔案（沒有一併帶著 `fonts/` 資料夾），或是
解壓縮、搬移檔案時資料夾結構跑掉，字體就會讀取失敗，瀏覽器會**悄悄地**改用系統預設字體頂替，
畫面上的文字就會變成完全不同的字體樣式（粗細、字寬都不一樣），看起來像「字體跑掉」。

這次比照先前修正圖片透明背景問題時的做法：把三個字體檔案直接轉成資料，內嵌寫進
`index.html` 檔案本身（不再讀取外部的 `fonts/` 資料夾）。也就是說，**現在只要有這一個
`index.html` 檔案，不管複製到哪台電腦、放在哪個資料夾，字體都一定會正確顯示**，不會再因為
檔案結構跑掉而受影響。

已實際測試：把 `index.html` 單獨複製到一個完全空的資料夾（刻意不放 `fonts/` 資料夾），開啟後
確認三個字重（Regular／Medium／Bold）都正常載入、畫面文字樣式正確，跟原本資料夾結構完整時
的顯示效果一致。

**唯一的取捨**：`index.html` 檔案大小因此變大很多（因為字體資料直接寫進檔案裡），從原本幾 MB
變成約 55MB。這是為了徹底解決「換電腦/搬檔案字體跑掉」問題所做的犧牲；除了檔案變大、開啟時
載入會慢一點點之外，不影響任何功能。

全部 9 個版位重新測試過渲染畫面與下載 PNG，皆正常無誤。

不變，兩者互不影響。換句話說：預設商品＝完全比照原始設計；您上傳的新商品＝依照它自己的比例
自動撐到合理大小，再用縮放滑桿與拖曳微調即可。

## 舊版（v7）修正紀錄
**圖素放大後被裁切**：v6 為了「拖曳不會蓋到其他欄位」，把每個圖片欄位的可視範圍鎖死在它預設
擺放的那個小框內，結果一放大，圖片馬上被那個小框裁掉大半。v7 改成每個圖片欄位除了原本「預設
擺放框」，另外有一個更大的「安全顯示範圍」，放大或拖曳時只會被這個更大的範圍裁切。

## 如何使用
直接雙擊 `index.html` 用瀏覽器打開即可（不需要安裝、不需要建置工具、不需要伺服器）。上方選單
切換 `LPBN_APP` / `副區_APP` 兩種版型，左邊改文字／換圖，右邊即時看到結果，按「下載 PNG / JPG」
輸出最終圖片（固定輸出版型原始尺寸：1200×550 或 1200×350，與畫面顯示大小無關）。

**圖片欄位操作**：
- 「上傳圖片替換」：選擇本機圖片後，會依照該圖片自己的長寬比例，盡量撐滿該欄位的安全顯示
  範圍（LPBN 商品欄位＝整個右側商品區塊；副區圖示欄位＝該格所在的整張卡片）。
- **滑鼠移到預覽圖上的商品／圖示上**：會顯示白色虛線外框，表示目前可以操作這個商品／圖示。
- **點選商品／圖示**：外框變成藍色實線＋四角控制點，並持續顯示（移開滑鼠也不會消失），直到
  點選其他商品或畫布空白處為止。
- **直接在右側預覽圖上拖曳圖片**：滑鼠移到選取中的商品／圖示上按住拖曳，即可調整位置，外框
  會即時跟著同步移動；可移動的範圍是該欄位的「安全顯示範圍」，超出這個範圍才會被裁掉。
- **拖曳四角控制點縮放**：選取後，滑鼠移到任一角落的控制點上（游標會變成縮放樣式），按住拖曳
  即可直接放大縮小，會以對角的角落為基準點，不會整張圖跳動位移。
- **拖曳圖層卡片調整前後順序**（僅 LPBN 左右商品欄位有）：商品圖片的卡片本身就是可拖曳的圖層
  列表，直接把某張卡片拖到另一張的上面或下面，兩者的疊放順序（含 Canvas 實際前後關係）就會
  立即互換；列表最上面＝畫面最前面。不需要重新上傳圖片。
- **點擊畫布空白處**（背景或文字區域）：取消目前的選取狀態，隱藏外框。
- 「還原預設圖片與位置」：恢復成原始設計內建的那組商品／圖示圖片、縮放比例與位置。
- 外框與控制點僅顯示在畫面預覽上，不會出現在下載的 PNG／JPG 檔案裡。

## 舊版（v6）修正紀錄

### 1. 文案大小、位置比原始檔案小 → 已找到根本原因並修正
問題不是字體本身選錯，而是**欄位方塊的高度設得太小**：程式的自動縮字邏輯（autoFit）除了會
檢查文字寬度是否超出方塊，也會檢查「字級 × 行高」是否超出方塊高度，一旦超出就會持續縮小字級。
前一版的方塊高度是直接沿用「示意圖」上标示的框線高度，這個框線其實只是設計師大略框出的可編輯
「位置」範圍，比實際文字所需的完整行高（含上下間距）還要緊繃，於是即使文字設定的字級（例如
56px）跟原始設計相符，仍會被自動再往下壓縮到只剩 30 出頭 px，看起來明顯偏小。

這次改用「實際比對 `LPBN_APP.jpg` / `副區_APP.jpg` 中每一段文字的真實像素寬高」的方式，反推
蝦皮思源黑體在多大字級下會產生同樣的視覺大小，同時把方塊高度加大到能完整容納該字級（且維持
文字方塊的**垂直中心點不變**，不影響版面其他位置），確保不會再被誤壓縮。修正後以程式比對，
主標題／次標題等欄位的文字寬高已與原始檔案誤差在 1～2px 內。

### 2. 兩個商品的位置／大小是否能自行調整 → 已新增拖曳與縮放功能
現在所有圖片欄位（不只商品，包含副區的三個圖示）都支援：
- 直接在預覽圖上拖曳來源圖片調整位置
- 縮放滑桿放大縮小（50%～250%）
- 移動／縮放的結果只會顯示在該欄位的固定框內（自動裁切），不會跑出框外影響其他區塊或底圖

### 3. 副區中間的券上傳後變小了 → 這是「等比例縮小置中」的預期行為，現在可以用新功能解決
當上傳圖片的長寬比例跟預設圖差異較大時，為了不讓圖片變形，系統會等比例縮到能完整放進框內，
因此周圍會留白、看起來比框線小。這版新增的「縮放」滑桿與拖曳功能，可以讓您手動放大／裁切
上傳的圖片，讓它更貼滿框選範圍，不再只能整張塞在中間。

## 仍然存在的限制
1. **LPBN 左右兩個商品欄位現在共用同一塊安全顯示範圍**：這代表理論上兩個商品的顯示區域是可以
   互相重疊的（例如把其中一個商品放大很多、拖到中間）；如果您只想要「左右各自獨立、不會互相
   影響」的嚴格分區，請告訴我，我可以改回各自獨立但較窄的範圍，只是這樣會重新出現「換不同比例
   商品時容易被裁切」的取捨。
2. **安全顯示範圍是預先設定好的固定區域**：副區每個圖示的安全範圍大約是該欄位所在的整張卡片，
   數值都在 `template.json` 每個欄位的 `clip` 裡，如果覺得還要再調整範圍大小，請告訴我要調整
   成多大。
3. **兩個商品的預設分割線是估算值**：Indomie 泡麵與 VIVA 沐浴乳在原設計中彼此緊鄰，分割點是
   目測抓的，非精確物件邊界；這只影響「內建預設商品圖」的顯示方式，不影響您上傳新商品圖。
4. **同一行內的雙色文字，簡化為單一顏色**：例如「GET $0」中「GET」與「$0」原本顏色不同，這版
   簡化成同一行統一用強調色（紅色），下一行維持副色（棕色）。
5. **拖曳／縮放的狀態不會保存到下載檔以外的地方**：每次上傳新圖片或切換版型後，該欄位的縮放
   ／位移會重置為預設，這是為了避免不同圖片之間的位置互相干擾。
6. **尚未做 Admin UI**：座標／字級／顏色／安全範圍目前需要直接編輯 `template.json`（與
   index.html 內嵌 JSON 同步）。

## 快速驗收清單
- 不改任何文字／圖片，與 `LPBN_APP.jpg` / `副區_APP.jpg` 原始完成圖逐一比對文字大小、位置，
  這次應該幾乎一致（誤差在 1～2px 內）。
- 在任一圖片欄位的預覽圖上直接拖曳，確認圖片會跟著移動、且不會超出該欄位的框選範圍。
- 拖曳縮放滑桿，確認圖片會等比例放大縮小，且移動/縮放後仍被正確裁切在框內。
- 上傳新圖片後，確認縮放與位置會重置為預設（100%、置中）；按「還原預設圖片與位置」可以完全
  恢復原始狀態。
- 下載 PNG／JPG，確認輸出結果與 Preview 畫面一致（含拖曳/縮放後的狀態）。
